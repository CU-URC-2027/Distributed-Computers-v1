# Export contents

This repository exports the active weeny_ws C2, OC, shared ROS interfaces and PTY
Arduino simulator, along with scripts, contracts, technical references, seven
Word guides and SVG/PNG maps. Protocol and component source files are unchanged.

Build/install outputs, Python caches, local process metadata and raw running or
test-session logs are excluded. Compact dated validation summaries and original
source inventories are included. Historical evidence may contain original local
paths; it records the environment of those runs, not a clone prerequisite.

The actual board firmware source is maintained separately from this ROS workspace.
Local simulation requires no physical Arduino. Powered motion and two-host network
acceptance have not been demonstrated by the local simulation tests.
